مشروع تحويلتي - نسخة تجريبية أولية

محتويات المشروع:
- App.js: واجهات عربية تجريبية.
- app.json: إعدادات تطبيق Expo.
- package.json: الاعتماديات.
- eas.json: إعداد بناء APK عبر Expo EAS.

مهم:
هذه ليست نسخة APK جاهزة. هذا مشروع المصدر الذي يجب بناؤه عبر Expo EAS.
النسخة الحالية للعرض فقط:
- لا تتصل بقاعدة بيانات.
- لا ترفع صور الهوية فعلياً.
- لا ترسل رسائل للمستشفى.
- لا تعرض بيانات تحويلة حقيقية.
- لا تستخدم بيانات مرضى حقيقية.

لإصدار APK:
1) رفع المشروع إلى حساب Expo.
2) إنشاء مشروع EAS وربط projectId في app.json.
3) تشغيل: eas build --platform android --profile preview
4) تنزيل ملف APK الناتج من صفحة البناء.

يلزم قبل الاستخدام الحقيقي موافقة المستشفى، وخادم آمن، وتسجيل دخول وصلاحيات،
وتشفير وحماية البيانات، وسياسة خصوصية، وربط رسمي بنظام التحويلات.
